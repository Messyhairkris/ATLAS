VtoT formatting practice and test document

Read each line, then apply the formatting the line asks for, using the slash
command shown in brackets or the voice command in quotes. When you have done
every line, save the document as .html and run the checker; it tells you which
lines really carry the formatting they claim.

New to VtoT? Work down the list. By the end you will have used every full-line
command once, and you will have a document that proves it.

Notes for the tester
- Three lines are deliberately two steps, because removing formatting matters
  as much as adding it: the checked box (checklist style, then tick it), the
  plain line (bold it, then clear it), and the body-text line (make it a
  heading first, then body text - which is how you clear a block style).
- The color list ends with a custom color option; the custom line is there to
  show you where it is.
- Left alignment is the default, so the checker accepts either an explicit
  left alignment or no alignment at all on that line.
- Page break and title page are not in the list: they produce no line of their
  own for the checker to find. Test them by hand by saving as .fountain and
  looking for the elements in the saved file. Automated coverage of saved-file
  shapes is deliberately deferred: not worth over-testing yet.
- Selection-based commands (bold a word, color a phrase) and the right-click
  menu are a separate document, still to be written.
